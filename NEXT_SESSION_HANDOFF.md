## Important Design Feedback

The current backstage sculptural pass is not the desired artistic direction.
From the side view it still reads as a few large clean arcs plus a front scribble.
The desired look is more like a dense intentional tangle: a compact rear knot or
groviglio that feels sculptural from non-camera views, while the privileged
camera still reveals the target.

Do not continue making larger elegant arcs. Replace them with a controlled
tangle cloud behind the readable target.

## Target Image Automation

If the image contents of `input/target_LOVE.png` are replaced with another
white-on-black target, most geometry recalibrates automatically:

- `scripts/00_autosize_config.py` analyzes the bitmap and updates target/lamp
  dimensions.
- Projection, skeleton extraction, path generation, LED mask, camera evaluation,
  validation, and export are regenerated by `scripts/run_all.py`.

The project is not fully generic yet:

- The filename `target_LOVE.png` is still hardcoded in multiple scripts.
- Output filenames still use `_LOVE`.
- Some debug object names and labels still mention LOVE.

Planned fix: introduce a shared target config with `target_id`,
`target_image_name`, and derived output names, then update every script to read
from that config instead of hardcoded LOVE constants.

## Next Technical Step

Implement a real `tangle_cloud` behavior for hidden connectors in
`scripts/04_continuous_path.py`.

Recommended approach:

1. Keep readable strokes on the target mask.
2. When leaving one readable stroke and entering the next, route through a
   compact rear tangle volume centered behind the word.
3. Generate several small loops or figure-eight motions per connector instead
   of one large arc.
4. Alternate depth lanes aggressively so the tangle looks layered, not flat.
5. Keep the tangle within lamp bounds using the existing camera-ray clamp.
6. Keep `mask_fit_fraction = 0.0` for hidden tangle points so the LED face
   twists away from the privileged camera there.
7. Regenerate the full pipeline and inspect side/three-quarter view before
   optimizing metrics.

Initial parameter direction:

- Reduce vertical escape arcs.
- Reduce side excursions.
- Increase local loop count.
- Use rear depth between roughly `45%` and `95%` of max sculptural depth.
- Keep camera visual score above `0.75`.
- Keep out-of-bounds at `0`.
